# React Booking Routing Demo

A small React + Vite project using **React Router DOM**.

## Features
- Booking page at `/`
- Clicking **Book Now** navigates to `/confirmation`
- Confirmation page displays **Booking Confirmed**
- Back to Home link returns to the booking page

## Run locally

1. Install [Node.js](https://nodejs.org/) (LTS version recommended).
2. Extract this ZIP.
3. Open a terminal in the extracted `react-booking-routing` folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Create a production build

```bash
npm run build
```

The production files will be generated in the `dist` folder.
